# Vois Studio

Vois Studio makes voiceovers, podcasts and audiobooks on your computer. You write the script, select the voices and export the audio. Your scripts stay on your computer.

The Vois Studio app is closed source. The repositories in this organization are open source. They connect Vois Studio to the tools that you use, and they help AI agents make audio with Vois Studio.
