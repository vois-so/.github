# Security policy

## Tell us about a security problem

Do not tell us about a security problem in a public issue, a discussion or a pull request.

Send an email to [support@vois.so](mailto:support@vois.so). Put "Security" in the subject. In the email, tell us:

- The name and the version, for example Vois Studio 2.6.2 or agent-voice 0.1.0.
- The steps that cause the problem.
- What an attacker can do because of the problem.

Do not send a license key, a password or personal data, unless the report cannot show the problem without it.

We send a reply to each report. When we correct the problem, we tell you. If you agree, we give you credit in the release notes.

## Versions that get corrections

We correct security problems in the latest version of Vois Studio and in the latest version of each repository in this organization.
