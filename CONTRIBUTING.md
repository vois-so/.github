# Contribute

Thank you. The Vois Studio app is closed source. The repositories in this organization are open source.

## Issues

- Before you open an issue, look for an issue about the same problem. If you find one, add a thumbs-up reaction to it. The reactions tell us which work to do first.
- Use the issue forms. Give the version, the operating system and the steps.
- Do not put a license key, an email address or a private script in an issue.

## Pull requests

- In `vois-so/vois-studio`, only the Vois Studio team can open pull requests. Open an issue.
- In the other repositories, open an issue first for a large change. For a small correction, open a pull request.
- Keep a pull request small, and tell us which tests you did.
- Public text, README files included, uses short sentences and simple words (ASD-STE100 Simplified Technical English).
- The checks must find no error in a pull request. The checks look for secrets, and for names of the parts in the Vois Studio engines. Public text names the engine (Fast, Expressive, Multilingual, Omni, Sonic or Craft), not its parts.

## License

Each repository has a LICENSE file. When you send a pull request, you agree that we can use your change with that license.
