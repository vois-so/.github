# Get help

| Help for | Go to |
| --- | --- |
| How to use Vois Studio | The [FAQ](https://vois.so/faq?utm_source=github&utm_medium=support&utm_campaign=oss), the [tutorials](https://vois.so/tutorials?utm_source=github&utm_medium=support&utm_campaign=oss) or [Discord](https://discord.gg/7e7fnE55Nh) |
| A problem in the Vois Studio app | An issue in [vois-so/vois-studio](https://github.com/vois-so/vois-studio/issues/new/choose) |
| A problem in an open-source repository | An issue in that repository |
| Billing, licenses or your account | An email to [support@vois.so](mailto:support@vois.so) |
| A security problem | The [security policy](https://github.com/vois-so/.github/blob/main/SECURITY.md) |

Do not put a license key, an email address or a private script in a public issue.
